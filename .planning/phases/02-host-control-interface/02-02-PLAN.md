<task type="auto" tdd="true">
  <name>Task 1: Server-side Game Controls & Validation</name>
  <files>server.js</files>
  <behavior>
    - drawNumber(n):
        - If !socket.isHost -> ignore
        - If n < 1 or n > 90 -> ignore
        - If gameState.drawnNumbers.includes(n) -> ignore
        - Success: push to drawnNumbers, set lastDrawn, emit numberDrawn(n)
    - resetGame():
        - If !socket.isHost -> ignore
        - Success: reset gameState, emit SYNC(gameState)
  </behavior>
  <action>
    - Implement `drawNumber` and `resetGame` listeners inside `io.on('connection')`.
    - Apply the `socket.isHost` check to both.
    - Add integer validation and duplicate checks for `drawNumber`.
    - Broadcast updates to all clients (including participants).
  </action>
  <verify>

  </verify>
  <done>Server correctly validates and broadcasts host actions</done>
</task>
